# Kasir Ku Garang Asem Podo Roso

Aplikasi kasir (PWA) untuk WM. Podo Roso Garang Asem. Bisa dipasang di Android dan jalan offline.

## Upload ke GitHub Pages
1. Ekstrak file ZIP ini di HP atau komputer.
2. Buat akun di github.com, lalu buat repository baru (misal: `kasir-podoroso`), pilih Public.
3. Klik **Add file > Upload files**, tarik SEMUA isi hasil ekstrak (termasuk folder `icons`), lalu **Commit changes**.
4. Buka **Settings > Pages**. Di Source pilih **Deploy from a branch**, branch **main**, folder **/ (root)**, lalu Save.
5. Tunggu 1-2 menit. Alamat aplikasi: `https://NAMA-GITHUB-ANDA.github.io/kasir-podoroso/`

## Pasang di Android
Buka alamat di Chrome, ketuk menu titik tiga, pilih **Instal aplikasi** (atau **Tambahkan ke layar utama**).

## Setelah terpasang
- Tab **Pengaturan**: unggah gambar QRIS warung, isi nomor rekening BRI, BNI, Mandiri, Bank Jateng, dan ubah nama di struk.
- Data (menu, riwayat, pengaturan) tersimpan di HP yang dipakai, tidak otomatis pindah ke perangkat lain.
- Jangan hapus data situs/cache Chrome, karena data ikut terhapus.
- Untuk memperbarui aplikasi: ganti file di repository, lalu buka aplikasi dengan internet menyala.
